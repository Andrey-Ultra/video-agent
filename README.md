# video-agent

MCP-сервер для сборки видео из смысловых фрагментов по текстовому запросу.

## Идея проекта

Исходные видео нарезаются на сцены и переводятся в эмбеддинги (модель X-CLIP). Дальше агент может семантически искать нужные фрагменты по текстовому описанию, посмотреть превью найденного сегмента и склеить из выбранных сегментов итоговое видео — всё как MCP-инструменты, доступные любому LLM-агенту.

Проект в активной разработке. Финальная форма пока не определена — возможно, вырастет в плагин для DaVinci Resolve, возможно — в самостоятельное приложение.

## Инструменты MCP

- **search_clips(query, top_k)** — семантический поиск видео-сегментов по текстовому запросу
- **get_clip_preview(segment_id)** — превью-кадр найденного сегмента
- **render_video(segments, output_path)** — склейка выбранных сегментов в один файл

## Стек

- Python
- MCP (Model Context Protocol)
- PyTorch, Transformers — эмбеддинги видео/текста (X-CLIP)
- ChromaDB — векторное хранилище для поиска сегментов
- PyAV, ffmpeg-python, Pillow — обработка видео и кадров
